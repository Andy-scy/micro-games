# 微游戏合集 · 1000 IN 1

> **在线试玩:https://andy-scy.github.io/micro-games/** (GitHub Pages) · 单文件版:[all-in-one.html](https://andy-scy.github.io/micro-games/all-in-one.html)

1000 款微型网页游戏,每款一个**独立、自包含、离线可玩**的 HTML 文件(原生 HTML/CSS/JS,零外部依赖,双击即玩)。全部由多智能体流水线按「**50 个系列 × 每系列 20 款**」生产,系列内每款游戏机制两两不同。

## 快速开始

- **单文件整合版**:双击打开 [all-in-one.html](all-in-one.html) —— 1000 款游戏**全部内嵌在这一个文件里**(约 9.4MB,无需 games/ 目录即可离线使用)。搜索后点击卡片自动"跳转"进入游戏(`#g-编号` 锚点,支持浏览器前进/后退),`Esc` 或「⌂ 返回目录」回到列表,另有「上一款 / 下一款」连续切换。
- **多文件版**:双击打开 [index.html](index.html) —— 合集首页,支持搜索、按系列浏览、点击卡片弹窗试玩、自动记录试玩进度(✓);游戏本体在 `games/` 下,每款一个独立 HTML。
- 也可以直接双击任意 `games/game-NNN.html` 单独游玩某一款。
- 若个别浏览器限制本地 iframe,可起一个静态服务:`python -m http.server 8080`,然后访问 http://localhost:8080。

## 目录结构

```
micro-games/
├── all-in-one.html 单文件整合版(1000 款全部内嵌,点击跳转即玩)
├── index.html      多文件版合集首页(搜索/分类/弹窗试玩/进度标记)
├── games/          game-001.html ~ game-1000.html(1000 款游戏本体)
├── SPEC.md         统一交付规范(所有智能体必须遵守)
├── families.json   50 个系列的定义与编号区间
├── goals/          50 份智能体专属目标存档(goal-NN-系列.md)
└── tools/          生产与校验工具(Python)
    ├── check.py        结构 + JS 语法(esprima)校验器
    ├── gen_index.py    合集首页生成器
    ├── gen_allinone.py 单文件整合版生成器
    └── gen_goals.py    智能体目标书生成器
```

## 统一规范(每款游戏)

- 单文件自包含,CSS/JS 全部内联,**零外部资源**(无 CDN/图片/字体/网络请求),离线可玩;
- 中文界面(标题/玩法说明/按钮/结算),深色主题,画面自适应,多数支持键盘 + 鼠标,触屏玩法补齐 touch;
- 有开始方式、实时得分、明确胜负条件、结算覆盖层与「再来一局」,重开完整重置状态;
- 原生 JS(ES2017 语法)+ Canvas/DOM,`requestAnimationFrame` 动画,无 alert、无 TODO、无第三方库。

## 质量校验

全部 1000 款已通过 `tools/check.py` 校验:**结构检查**(DOCTYPE/lang/title/体积/无外部资源/无 alert/无 TODO)+ **JS 语法严格解析**(Python esprima)。

复跑全量校验:

```bash
python tools/check.py          # 1-1000 全量
python tools/check.py 141 160  # 指定区间
```

> 说明:校验覆盖「结构 + 语法」与各智能体的逐款自查;未做全量人工试玩,个别游戏如遇体验问题可直接编辑对应单文件(互不影响)。

## 生成架构(复现)

1. `SPEC.md` 统一规范 + `families.json` 定义 50 个系列与编号区间;
2. `gen_goals.py` 生成 50 份智能体专属目标书(`goals/`);
3. 每个系列派发 1 个独立智能体(专属 GOAL,生产 20 款并自检全绿),分波次并行;
4. 波次间隙用 `check.py` 验收,缺口由修复智能体补齐;
5. `gen_index.py` 汇总 1000 款生成合集首页 `index.html`。
